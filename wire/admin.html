Connect Supabase first

The newsroom needs a database before it can do anything.

  1. Create a project at supabase.com.
  2. Open the SQL Editor and run supabase-schema.sql from this folder, top to bottom.
  3. Go to Project Settings → API and copy the Project URL and the anon public key.
  4. Paste both into wire/config.js, commit, and reload this page.
  5. Create your login under Authentication → Users, then add yourself to the staff table (the SQL file ends with the exact command).
